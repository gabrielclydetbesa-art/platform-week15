# platform-week15

Campus Records is a small Student Information System prototype built for Platform Technologies Week 15 (DevOps, Deployment, and Operations).

## What it does

- Lists enrolled students in a searchable table
- Adds new students with form validation
- Removes student records
- Shows live totals for students, enrolled students, and courses
- Works on phones, tablets, and desktops

Records are kept in the browser's local storage, so no server or database is needed.

## Files

| File | Purpose |
| --- | --- |
| index.html | Page structure and content |
| style.css | Layout, colors, and responsive rules |
| script.js | Search, add, remove, validation, and totals |

## Run it locally

Open `index.html` in any modern browser. No installation is required.

## Deployment

The site is deployed from the `main` branch of this repository.

1. Push changes to GitHub.
2. Netlify or Vercel detects the new commit.
3. The platform publishes the new version automatically.

Publish directory: repository root. Build command: none.
